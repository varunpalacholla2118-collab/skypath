# SKYPATH — Intelligent Flight Planner (works with zero setup)

This version needs **nothing installed** — no Node.js, no server, no
terminal commands. Just open the page.

```
skypath/
├── index.html      ← double-click this
├── css/
│   └── style.css
└── js/
    └── app.js
```

## How to open it

1. Unzip the folder.
2. Double-click **index.html**.
3. It opens in your default browser (Microsoft Edge, Chrome, etc.) and
   works immediately — create an account and start planning flights.

That's it — there's no server to start and no "cannot reach the
server" screen, because everything runs inside the page itself.

## How it works

- All the app logic (accounts, flight search, profile, history, the AI
  assistant) runs as plain JavaScript in your browser.
- Your account, searches and preferences are saved with the browser's
  built-in storage (`localStorage`), tied to this folder/page. Closing
  and reopening `index.html` keeps your data; it does **not** sync
  between different computers or browsers, since there's no real
  server behind it.
- Flight results are generated by a deterministic algorithm, so
  searching the same From/To/Date always returns the same routes —
  similar to a cached fare search.
- This is a self-contained demo, not a secure multi-user system —
  please don't reuse a real password when creating an account here.
